## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Task_online_store)
2. Установите зависимости
   (`pip requirements.txt`)

## Использование:

1. Откройте проект.
2. Запустите проект.
3. Откройте в браузере сайт по ссылке интернет магазина [sky_store](http://127.0.0.1:8000/)
